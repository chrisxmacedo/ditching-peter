# DitchingPeter.com

A single-page site presenting the **ARA framework** (Authority, Responsibility, Ability) — a path to organisational health.

Static HTML, no build step. Deployed on Vercel.

## Structure

- `index.html` — the entire site (self-contained: inline CSS + JS, Google Fonts via CDN)
- `vercel.json` — Vercel config (clean URLs)

## Deploy

```bash
vercel --prod
```
